# Rashmika & Mihira — A Beautiful Beginning

A wedding invitation for Rashmika and Mihira, combining their supplied wedding banner artwork with pearl ivory paper, gold ornaments, and elegant serif typography. The couple's names and illustration make the invitation personal, with layouts that adapt to mobile phones, tablets, and desktops.

## Open the invitation

Double-click **index.html**. No installation, build, API keys, or server is needed. You can also upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder to any static web host.

## Files

- `index.html` — the invitation, details, venue, countdown, and final welcome.
- `style.css` — responsive layouts, animation, local fonts, and print styles.
- `script.js` — live countdown, mobile navigation, golden particles, and motion controls.
- `assets/` — the supplied couple banner, decorative artwork, SVG ornaments, local fonts and their licenses, and the downloadable calendar invitation.

The page's artwork, fonts, and interactions work offline. The **View location on map** link opens Google Maps and requires an internet connection. The map preview is a decorative illustration; the floral image is original atmospheric artwork, not a photograph of the hotel.

`assets/rashmika-mihira-banner.png` is an unchanged copy of the supplied `Rashmika and Mihira Wedding Banner (1).png`. The website uses CSS to frame the couple illustration without altering the source image.

## Event information

- Poruwa Ceremony: 10:00 AM

The countdown and calendar use **Sri Lanka time (UTC+05:30)**. The calendar begins at `2026-11-05T03:30:00Z`; no unspecified finish time has been added. Open the downloaded `.ics` file in your calendar application to save the event.

To change the event, update the visible details in `index.html`, the two event date constants in `script.js`, and `assets/wedding.ics` together. Update the map search URL if you change the venue.

Visitors can pause decorative motion with the small control at the bottom right. System reduced-motion preferences are respected. The layout includes keyboard focus styles, a skip link, accessible mobile navigation, and a static invitation fallback when JavaScript is disabled.

Font licenses and artwork provenance, including the supplied banner and the floral artwork's generation details, are included in `assets`.
