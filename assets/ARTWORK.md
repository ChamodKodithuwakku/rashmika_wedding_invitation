# Wedding invitation artwork

`rashmika-mihira-banner.png` is an unchanged copy of the user-supplied `Rashmika and Mihira Wedding Banner (1).png`. It provides the wedding couple's artwork for Rashmika and Mihira's invitation. The website frames the couple illustration with CSS; the original image file is preserved without editing or regeneration.

`ivory-florals.png` was generated with the built-in image generation tool for this website. It is an atmospheric still life, not an image of the event venue. The supplied invitation's ivory-and-gold palette also informs the surrounding design.

Style: high-end editorial wedding photography, tactile silk, natural imperfect rose petals, understated European fine-art stationery mood, luminous soft morning window light, warm off-white monochrome palette with muted champagne gold, gentle film grain. No people, no letters, no writing, no logos, no frames, no invitation card, no venue or building. Create a real atmospheric still-life photograph, not a website mockup.
